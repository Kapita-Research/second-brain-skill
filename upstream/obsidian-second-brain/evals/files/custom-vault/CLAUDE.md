# Vault Guide for Claude
My Obsidian vault uses MY layout — follow it, not any default:
- `00 Inbox/` capture · `01 Notes/` knowledge · `03 People/` person notes
- `04 Meetings/` all meeting notes (type: meeting)
- `05 Actions/` task notes (type: task) — one note per task, status not-started|doing|done
Rules: every note gets type/domain/created. Task status vocabulary here is not-started | doing | done (this vault deliberately uses `doing`, not `in-progress`). Never create folders outside this list without asking.
